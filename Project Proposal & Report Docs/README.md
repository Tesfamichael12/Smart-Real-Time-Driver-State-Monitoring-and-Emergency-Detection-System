# Project Proposal & Report Docs

This folder contains the academic documentation, proposal, progress reports, and reference specifications for the **Smart Real-Time Driver State Monitoring and Emergency Detection System** developed by Group 5.

## Document Directory

### 1. Project Proposal
* **File Name**: `Smart_Real_Time_Driver_State_Monitoring_Proposal.pdf`
* **Contents**: Details the initial project design parameters, problem statement (rising vehicular accidents due to driver fatigue, distraction, and delayed emergency response), proposed system architecture (Computer Vision + Embedded Hardware + Web UI), and implementation roadmap.

### 2. Progress Report
* **File Name**: `Group 5 Project Progress Report - Smart Real-Time Driver State Monitoring and Emergency Detection System.pdf`
* **Contents**: Mid-development status update documenting the functional computer vision module (MediaPipe/EAR/MAR/Posture metrics), the ESP32 Wokwi circuit simulation details, serial bridging logic, and the web interface layout.

### 3. Final Project Report / Documentation
* **File Name**: `Smart Driver Monitoring and Emergency Detection.pdf`
* **Contents**: The comprehensive final document detailing software design specifications, mathematical models (EAR/MAR formulas), hardware schematic configurations, evaluation metrics, and system verification results.
